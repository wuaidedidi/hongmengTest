# HarmonyOS 短视频应用

一个基于 HarmonyOS/ArkUI 开发的抖音风格短视频应用，实现了核心的短视频浏览、交互和社交功能。

## 🎯 项目特色

### 核心功能
- **沉浸式视频体验** - 全屏垂直滑动视频流，支持点赞、关注、分享等互动
- **智能内容推荐** - 四个内容标签：推荐、关注、商城、团购
- **社交互动** - 好友系统、消息通知、创建中心
- **流畅动画** - 丝滑的页面切换和交互动效

### 技术亮点
- **响应式设计** - 适配不同屏幕尺寸，保持最佳视觉效果
- **状态管理** - 集中式状态管理，数据驱动界面更新
- **组件化架构** - 高度模块化，易于维护和扩展
- **手势交互** - 支持多种手势操作，提升用户体验

## 📱 应用界面

### 主要页面
1. **视频首页** - 沉浸式视频流浏览
2. **顶部标签栏** - 内容分类切换
3. **底部导航** - 主要功能入口
4. **好友抽屉** - 右侧滑出的好友列表
5. **创建菜单** - 底部弹出的创作选项

### 交互设计
- 垂直滑动切换视频
- 点击视频进行点赞
- 点击头像关注用户
- 滑出抽屉查看好友动态
- 弹出菜单进行内容创作

entry/src/main/ets/

## 🎨 设计系统

### 颜色主题
- **主色调**: 抖音红色 (#FE2C55)
- **背景色**: 纯黑色 (#000000)
- **文本色**: 白色系，保证可读性
- **功能色**: 成功、警告、错误等状态色

### 组件规范
- **按钮尺寸**: 48x48px 标准触摸区域
- **头像尺寸**: 48px 圆形头像
- **间距系统**: 4px 基础间距，8px/16px/24px 等倍数间距
- **字体系统**: 10px-48px 字体大小，支持不同权重

### 动效规范
- **页面切换**: 200ms ease-out 过渡
- **点击反馈**: 150ms 快速缩放
- **弹出动画**: 220ms ease-out 滑入
- **加载动画**: 线性旋转或弹性缩放

## 🚀 开发指南

### 环境要求
- HarmonyOS SDK 4.0+
- DevEco Studio 4.0+
- ArkTS 语言支持

### 构建运行
```bash
# 构建项目
hvigorw assembleApp

# 构建调试版本
hvigorw assembleApp --mode debug

# 构建发布版本
hvigorw assembleApp --mode release
```

### 开发流程
1. **克隆项目** - 下载源码到本地
2. **导入IDE** - 使用 DevEco Studio 打开项目
3. **配置环境** - 设置 HarmonyOS SDK 和模拟器
4. **运行调试** - 在模拟器或真机上运行
5. **修改功能** - 根据需求修改组件和逻辑

## 📊 数据模型

### 核心实体
- **VideoItem** - 视频信息（ID、URL、创作者、描述、音乐、互动数据）
- **Creator** - 创作者信息（ID、名称、头像、认证状态）
- **Friend** - 好友信息（在线状态、最后活跃时间）
- **Notification** - 通知信息（类型、内容、时间、已读状态）

### 状态管理
- **导航状态** - 当前选中的标签和页面
- **视频状态** - 播放状态、当前视频索引、进度
- **交互状态** - 抽屉开关、菜单显示、用户偏好
- **数据状态** - 好友列表、通知列表、未读数量

## 🔧 技术实现

### 组件架构
- **主页面** - MainPage.ets 作为应用入口
- **组件化** - 每个功能模块独立组件
- **状态驱动** - 通过 appStore 管理应用状态
- **响应式** - 组件自动响应状态变化

### 性能优化
- **懒加载** - 视频内容按需加载
- **缓存机制** - 状态和数据的本地缓存
- **内存管理** - 及时释放不需要的资源
- **动画优化** - 使用硬件加速的动画效果

### 手势处理
- **点击事件** - 点赞、关注、导航切换
- **滑动手势** - 视频切换、页面滚动
- **长按事件** - 暂停播放、显示选项
- **双击事件** - 快速点赞（预留）
